高分子マスター Webアプリ

GitHub Pagesへのアップロード用ファイルです。

1. GitHubで新しいPublicリポジトリを作成
2. このフォルダ内の全ファイルをリポジトリ直下へアップロード
3. Settings > Pages > Deploy from a branch
4. Branch: main / Folder: /(root) を選んで Save
5. 公開URLをSafariで開く

ホーム画面への追加（iPhone）:
Safariの共有ボタン > ホーム画面に追加 > 追加

注意: GitHub Pagesのサイトとリポジトリは公開状態になります。個人情報や秘密情報を入れないでください。
